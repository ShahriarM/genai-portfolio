## Note on the OCC booklet

`OCC-model-risk-booklet-2021` is the OCC *Comptroller's Handbook* booklet "Model Risk Management", version 1.0, August 2021 (109 pages). It is the guide OCC examiners used when reviewing a national bank's model risk management, so it describes what examiners look for, not what banks must do.

The OCC rescinded it by OCC Bulletin 2026-13, when SR 26-2 replaced the older model risk guidance, and the OCC no longer hosts it. This copy was downloaded from radicalcompliance.com, a third-party site, so it is not an official OCC download. It is used here only as a second public source for the embeddings exercise, not as current guidance.

The `.txt` files were extracted with `pdftotext -layout`.
